🍀 신입생 면접자료 정리

면접 결과 취합 → 검토 → 반편성용 자료 내보내기
STEP 1

⚙️ 학급 수

실제 반 배치와 인원 균형은 스마트 반편성 앱에서 수행됩니다. 여기서는 참고 정보로만 쓰입니다.

✅ 관찰 영역 선택

선택한 영역의 문항만 면접 서식·설문지에 포함되고, 검토·내보내기에도 선택한 영역만 표시됩니다. 점수가 높은(주의가 필요한) 학생을 각 영역별로 표시해두면, 실제 반 배치에서 고루 나눠 배치하는 건 스마트 반편성 앱이 맡습니다.

STEP 2

📋 신입생 명단 등록

이름·성별만 등록하면 학생마다 고유한 관리번호를 자동으로 부여합니다. 면접교사는 이 번호를 그대로 옮겨 적기만 하면 되어 오타·중복 문제를 막을 수 있습니다.

관리번호이름성별구분 메모

⬇ 면접 서식 받기

📌 현재 설정: 학급 5개 · 관찰 영역 8개 사용 · 명단 0명 (미확정)
① 다운로드 → ② 면접교사에게 배부 → ③ 작성 후 업로드로 이동

📄면접 결과 업로드

학생 면접은 교사가 엑셀에 입력하지만, 학부모 설문은 학부모가 직접 응답하는 자료입니다. 걷은 뒤에는 담당자가 면접용 서식의 '학부모확인' 시트에 일괄로 옮겨 적어 업로드하면 됩니다. 서식·설문지는 준비 단계에서 받을 수 있습니다.
