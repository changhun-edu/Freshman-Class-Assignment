PC(데스크톱)에서 이용해 주세요

신입생 면접자료 정리 도구는 대량의 표 데이터를 다루기 때문에 PC 환경 전용으로 제작되었습니다. 학교 컴퓨터나 노트북에서 접속해 주세요.

🏫 스마트 반편성 (신입생용)

🔒개인정보 미저장 · 작업 후 엑셀로 내보내세요
📂 이미 면접 서식 파일이 있으신가요?
면접 결과가 입력된 엑셀 파일이 있다면 아래 단계를 건너뛰고 바로 업로드하세요.
STEP 1

✅ 관찰 영역 선택

선택한 영역의 문항만 면접 서식·설문지에 포함되고, 검토·배치에도 선택한 영역만 반영됩니다.

STEP 2

📋 학생 문항 출력 & 학부모 설문 방식 결정

📌 현재 설정: 관찰 영역 8개 선택됨
선택한 관찰 영역의 면접 문항 · 채점 기준표
① 출력 → ② 면접 당일 학부모에게 배부 → ③ 회수 후 담당자가 취합

Apps Script를 이용해 구글폼을 자동으로 생성합니다. 생성된 폼 링크를 학부모에게 배포하세요.

스크립트 복사 → Apps Script에 붙여넣기 → 실행 → 폼 자동 생성

네이버폼 "문항 가져오기" 기능을 이용해 설문을 자동으로 구성합니다.

엑셀 다운로드 → 네이버폼 가져오기 → 문항 자동 생성

서버 없이 배포 가능한 독립 HTML 설문지를 생성합니다. 구글 드라이브나 학교 서버에 올려 QR코드로 배포하세요.

HTML 다운로드 → 드라이브 업로드 → QR코드 배포 → 응답 CSV 수집 → 업로드
STEP 3

📋 신입생 명단 등록

이름·성별만 등록하면 학생마다 고유한 관리번호를 자동으로 부여합니다.

📥 엑셀로 명단 추가 (권장)
① 양식 다운로드 → ② 이름·성별 입력 → ③ 파일 업로드 → 명단 자동 추가
✏️ 직접 입력 또는 붙여넣기
관리번호이름성별구분 메모이주배경

⬇ 면접용 서식 다운로드

명단을 확정하면 관리번호가 포함된 면접용 엑셀 서식을 받을 수 있습니다.

① 다운로드 → ② 면접교사에게 배부 → ③ 작성 후 업로드로 이동
💡 명단 미등록 상태입니다. 업로드 후 관리번호가 일치하지 않으면 수동 매핑이 필요할 수 있습니다.

📄면접 결과 업로드

학생 면접은 교사가 엑셀에 입력하고, 학부모 설문은 담당자가 면접용 서식의 '학부모설문' 시트에 옮겨 적어 업로드하면 됩니다. 서식·설문지는 준비 단계에서 받을 수 있습니다.

📋 구글폼 자동 생성 안내

Apps Script를 이용해 구글폼을 자동으로 만듭니다. 아래 순서대로 따라하세요.
1
스크립트 코드 복사
아래 버튼을 눌러 코드를 클립보드에 복사하세요.
✅ 복사되었습니다!
2
Google Apps Script 열기
아래 링크를 클릭해 새 탭에서 스크립트 편집기를 여세요.
🔗 script.google.com/create → 클릭하여 열기
3
붙여넣기 → 저장 → 실행
⚠️ 반드시 먼저 — 편집기의 기존 내용을 전체 선택(Ctrl+A) 후 삭제하세요!
복사한 코드를 붙여넣은 뒤 💾 저장(Ctrl+S) 후 ▶ 실행 버튼을 누르세요.
⚠ 처음 실행 시 Google 권한 허용 팝업이 뜹니다. "허용"을 눌러주세요.
4
실행 로그에서 배포 링크 확인
실행 완료 후 하단 실행 로그에서 배포 링크를 복사해 학부모에게 공유하거나 QR코드로 변환하세요.
✅ 실행 로그 예시:
▶ 설문 배포 링크: https://docs.google.com/forms/d/e/…/viewform
5
응답 수집 후 CSV 내보내기
응답이 모두 수집되면 같은 스크립트 편집기에서 함수를 createForm → exportToCSV로 바꾼 뒤 실행하세요. 실행 로그에 CSV 파일 링크가 뜹니다. 다운로드 후 이 사이트 업로드 탭에서 가져오면 자동 반영됩니다.
💡 CSV는 이 사이트의 학부모설문 시트 형식과 자동으로 맞춰져 생성됩니다.
